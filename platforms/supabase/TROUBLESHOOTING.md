# Supabase Troubleshooting

Supabase-specific failure တစ်ခုကိုမှတ်မယ်ဆိုရင် Problem → Evidence → Root Cause → Fix → Verification → Prevention အစဉ်လိုက်ရေးရမယ်။

RLS, migration, RPC, pgvector, timeout, connection, data isolation စတဲ့ failure တွေမှာ assumption မလုပ်ဘဲ query result, logs, schema/migration state နဲ့ reproducible test ကို evidence အဖြစ်သုံးရမယ်။
