# n8n Troubleshooting

Failure တစ်ခုဖြစ်ရင် workflow ကိုအကုန်ပြန်ဆောက်တာကို default မလုပ်ရ။

အစဉ်:
1. Reproduce
2. Execution evidence/logs စစ်
3. Failing node/contract ကို isolate လုပ်
4. Root cause verify လုပ်
5. Smallest safe fix လုပ်
6. Regression scenario စစ်
7. Production publish လိုရင် approval ရယူ
8. Verified learning ကိုမှတ်

Known mistake တစ်ခုကို automated workflow validation/test နဲ့တားနိုင်ရင် textual warning ထက် validation ကိုဦးစားပေးရမယ်။
