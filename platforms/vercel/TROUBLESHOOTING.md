# Vercel Troubleshooting

Verified Vercel-specific failures ကိုသာ ဒီမှာမှတ်မယ်။ Guess ကို root cause အဖြစ်မရေးရ။

Entry format:
- Problem
- Evidence
- Verified root cause
- Fix
- Verification
- Prevention / regression guard
- Related ticket or ADR

Reusable prevention rule ဖြစ်လာရင် `learnings/LESSONS.md` သို့ promote လုပ်ပြီး automated check ဖြစ်နိုင်ရင် documentation ထက် test/check ကိုဦးစားပေးရမယ်။
