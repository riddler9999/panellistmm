# AI Architect Project Context

Panellist is an AI-assisted HR operations system using n8n for orchestration and Supabase for persistent state/data where needed.

Current architecture domains:
- Discovery / intent routing
- HR Consultant
- SOP generation
- Org Chart generation
- HITL review and operational safeguards

Canonical diagram output for SOP and Org Chart is `.drawio`.

Material architecture changes require explicit human approval and an ADR when they alter durable system boundaries or contracts.
