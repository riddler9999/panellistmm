# Implementation Plan

ဒီ file က approved architecture ကို implementation phases အဖြစ်ပြောင်းဖို့သုံးမယ်။ လက်ရှိမှာ implementation မစသေးဘူး။

## Gate
Implementation plan တစ်ခုကို active မလုပ်ခင် အောက်ပါအချက်တွေရှိရမယ်။
- Approved scope
- Relevant requirements
- Approved architecture / ADRs
- Acceptance criteria
- Verification strategy

## Rule
Architecture သို့မဟုတ် scope ကိုပြောင်းဖို့လိုလာရင် implementation ကိုရပ်ပြီး owner approval တောင်းရမယ်။ ဒီ file ကို project history အဖြစ် append-only diary မလုပ်ရ။ Current approved implementation sequence ကိုပဲထိန်းထားရမယ်။
