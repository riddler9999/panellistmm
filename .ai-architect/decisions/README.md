# Architecture Decision Records (ADR)

ဒီ folder က material architecture decisions တွေရဲ့ canonical home ဖြစ်တယ်။ `DECISIONS.md` လို duplicate decision log ထပ်မဖန်တီးရ။

ADR တစ်ခုမှာ အနည်းဆုံး အောက်ပါအချက်တွေပါရမယ်။
- Context
- Decision
- Alternatives considered
- Consequences
- Status: Proposed / Accepted / Superseded
- Verification or enforcement mechanism ရှိရင် link

Naming: `ADR-001-short-title.md`

Agent က accepted ADR နဲ့ conflict ဖြစ်တဲ့ change ကို owner approval မရှိဘဲ implement မလုပ်ရ။
