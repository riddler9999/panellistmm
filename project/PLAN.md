# Project Plan

## Goal
Build Panellist as an AI-assisted HR operations product with controlled agent workflows, human approval gates, and reproducible engineering practices.

## Delivery sequence
1. Establish project operating system and architecture baseline.
2. Define product scope and requirements.
3. Build and stabilize Discovery routing.
4. Build HR Consultant capability.
5. Build SOP generation with `.drawio` as the canonical diagram output.
6. Build Org Chart generation with `.drawio` as the canonical diagram output.
7. Add review, audit, fallback, and operational safeguards.
8. Validate end-to-end flows before production release.

## Change control
Material changes to scope, architecture, production data, deployment strategy, secrets, destructive operations, or external communications require explicit human approval.
