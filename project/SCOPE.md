# Project Scope

## In scope
- HR consultation workflows
- Discovery and intent routing
- SOP generation
- Organization chart generation
- `.drawio` diagram output
- Human-in-the-loop review where required
- Company/user scoping
- Auditability, fallback, timeout, and failure handling
- Supabase-backed state and knowledge where applicable
- n8n orchestration
- Web/admin surfaces where required

## Out of scope unless explicitly approved
- Unrelated CRM/ERP modules
- Autonomous production deployment
- Unapproved destructive database operations
- Silent architecture changes
- PNG as the canonical SOP/Org Chart generation format
